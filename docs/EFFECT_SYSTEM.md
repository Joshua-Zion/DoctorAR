# DoctorAR 特效系统

## 1. V1 / V1.1 目标

V1 的视觉目标是“清晰、原创、实时的几何法阵”，而不是复刻任何电影画面。法阵主体由 Three.js 几何、Shader 和粒子动态生成，不使用电影截图、角色 Logo、电影原声或受保护的具体图案。

当前 V1 / V1.1 特效范围：

- 单手跟随小型法阵。
- 握拳收缩和一次能量爆裂。
- 双手中点大型法阵。
- 多层反向旋转圆环。
- 动态中心能量核心。
- 基础发光、呼吸亮度和火花粒子。
- 拇指与食指中点的能量点，以及会自动衰减的自由空中轨迹。
- 严格双手快速展开后覆盖到视口最远角的冲击波。
- 持续能量、轨迹与冲击波的原创 Web Audio 合成音色。

## 2. 输入边界

特效系统只接收框架无关的数据：

- 离散生命周期事件：开始、结束、握拳爆裂、捏合开始/结束和双手释放。
- 连续姿态：位置、尺寸、角度、透明度、双手距离和速度。
- 用户配置：主题、全局尺寸、亮度、粒子开关、粒子数和粒子速度。

特效模块不得导入 MediaPipe，不读取视频元素，也不自行判断手指状态。

## 3. 渲染结构

### 单手法阵

- 透明平面或程序化圆盘。
- 外环和内环使用不同角速度。
- 刻度、放射线和原创多边形符号。
- 中央能量核心及径向高光。
- 随手掌宽度缩放，随手掌角度调整基础旋转。

### 双手法阵

- 位于双手平滑中点。
- 尺寸由双手距离映射并限幅。
- 使用比单手法阵更多的同心层级。
- 相邻圆环反向旋转，中心能量更强。
- 激活时展开，结束时收缩或渐隐。

### 握拳爆裂

- 仅响应一次 `FIST`。
- 当前法阵快速收缩。
- 生成有寿命的径向粒子。
- 完成后效果进入不可见或等待重新张掌状态。

### 捏合能量点与轨迹

- 能量点位置来自拇指尖与食指尖中点。
- `PinchTrailEffect` 用一个固定容量 InstancedBufferGeometry 绘制轨迹段，并单独绘制发光能量点。
- 只有移动距离达到当前性能档的采样间距才追加轨迹段；能量点和轨迹都按时间自动衰减。
- 当前只表达自由轨迹与简单符号，不包含圆形闭合识别。

### 双手释放冲击波

- 只响应严格状态机发出的 `TWO_HAND_RELEASE`，视觉层不自行推断两手是否快速展开。
- `ShockwaveEffect` 使用固定槽位和单个实例化绘制调用。
- 每个实例的目标半径按触发点到视口四角中的最远距离再加安全边距计算，确保冲击波越过最远角，而不是使用固定屏幕半径。

## 4. Shader 原则

V1 Shader 至少负责一部分以下视觉：

- 径向渐变和高亮中心。
- 发光边缘。
- 时间驱动的亮度呼吸。
- 圆环旋转或流动。
- 轻量噪声扰动。

Shader uniform 只在渲染循环中更新，不通过 React state 每帧驱动。V1 不把 Bloom、色差、折射、屏幕空间扭曲和动态模糊列为已完成；这些属于 V2 后处理。

V1.1 新增两组独立 Shader：

- `pinchTrail`：按轨迹年龄与寿命渐隐，叠加流光、闪烁和发光能量点。
- `shockwave`：绘制扩散圆环、回波、径向光束、噪声与中心闪光。

## 5. 主题配置

颜色必须从统一主题对象读取。预留主题：

| 主题 | 主色方向 |
| --- | --- |
| Orange Gold | 橙金、高亮白、深橙边缘 |
| Space Blue | 蓝青、冷白高光 |
| Chaos Purple | 紫色、洋红高光 |
| Nature Green | 绿色、淡金高光 |
| Flame Red | 红色、橙白核心 |

主题至少统一控制主色、边缘色、高光、核心、粒子和发光强度。材质或组件中不得出现与主题重复的散落硬编码颜色。

## 6. 粒子生命周期

每个粒子至少包含：

- position、velocity、age、lifetime。
- size、alpha、color。
- 适量随机速度和寿命。

系统必须：

- 设置活动粒子硬上限。
- 到期后回收或删除粒子。
- 关闭粒子开关时停止新发射，并让已有粒子自然结束或立即安全清空。
- 在效果结束和页面卸载时释放 GPU buffer。
- 避免逐帧创建大量临时 Vector、Color 和数组。

当前粒子、轨迹和冲击波均使用固定容量，配置上限如下：

| 预设 | 活动粒子上限 | 轨迹段上限 | 冲击波槽位上限 |
| --- | ---: | ---: | ---: |
| Low | 360 | 96 | 2 |
| Balanced | 720 | 192 | 4 |
| High | 1200 | 320 | 6 |

轨迹段的采样间距分别为 9、6、4 CSS 像素。切换性能档只改变当前可用上限与参数，不在运行时扩大底层最大缓冲；达到上限时复用固定槽位。

## 7. 动画与时间

所有动画使用真实 delta time，不假定固定 60 FPS。需要对恢复后台标签页后的异常大 delta 做限幅。

建议的效果阶段：

- Enter：从小到大展开并提高透明度。
- Active：反向旋转、亮度呼吸和低量粒子发射。
- Exit：收缩或渐隐。
- Burst：握拳时一次性扩散并在寿命结束后清理。

跟踪短暂丢失时，效果进入保持/渐隐而非立即 dispose；确认结束后再销毁或回收到池中。

## 8. 渲染顺序与透明度

- WebGL Canvas 使用透明背景叠加在摄像头上。
- 视觉层不得拦截控制面板的鼠标或触摸事件。
- 透明材质需要稳定的 blending 和 renderOrder，避免圆环、核心和粒子随机穿插。
- Renderer 的尺寸和 DPR 与统一坐标映射同步，DPR 应有限幅。

## 9. 资源释放

Effect Manager 对其创建的所有资源负责：

- Geometry / BufferGeometry。
- Material / ShaderMaterial。
- Texture / CanvasTexture。
- RenderTarget 和后续后处理资源。
- requestAnimationFrame。
- 粒子数组、池和事件订阅。

dispose 之后不得继续持有场景节点或 uniform 中的大对象引用。

## 10. 音频生命周期

- 音色由 Web Audio 振荡器、滤波器、增益和声像节点原创合成，不依赖电影原声或外部音频素材。
- 法阵蓄力使用持续能量声部；左右手捏合各自复用持续轨迹声部；冲击波使用一次性释放声部。
- `PINCH_MOVE` 只更新现有节点的频率、滤波、增益与声像，并有更新节流，不为每个轨迹点创建新节点。
- 音效默认关闭；禁用或销毁时渐隐并清理节点，浏览器用户交互解锁限制仍然适用。

## 11. 当前完成状态与 V2 边界

V1.1 的捏合能量点、衰减轨迹、严格快速展开冲击波、持续/轨迹/冲击波音色、新 Shader 和固定容量限制均已实现。2026-08-01 无头 Edge 假摄像头生产预览烟测已确认这些 V1.1 效果进行了实际 WebGL 绘制且无页面异常、控制台或网络错误；真实摄像头、长稳与跨浏览器验证仍未完成。

V2 保持为：

- 人像 mask 遮挡。
- 掌面透视和更真实的三维方向。
- Bloom、色差、折射、空间扭曲和动态模糊。
