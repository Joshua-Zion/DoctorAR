# DoctorAR 已知问题

本文件记录当前 V1 / V1.1 的真实边界。列表中的限制不代表应用无法演示，但在解决前不得把对应能力写成已完成。

## 1. 识别与线程

- MediaPipe Hand Landmarker 默认在 ImageBitmap Worker 内运行，并保持单个 in-flight 请求；Worker 初始化或首次运行失败时会受控回退到最高 18 FPS、低档输入尺寸的主线程路径，同步 `detectForVideo` 在较慢设备上仍可能造成短帧。
- ImageBitmap 缩放、创建和消息往返仍有成本；WORKER 后端不等同于所有设备都达到 100 ms 内端到端延迟。
- Hand Landmarker 不提供逐关键点实时置信度。调试界面只能显示 handedness 分数、模型配置门槛和 DoctorAR 派生的手势置信度。
- 两手交叉、互相遮挡或快速交换屏幕位置时，handedness 和手部顺序可能短暂不稳定。
- 暗光、运动模糊、手部出画、手背、侧掌以及手指互相遮挡会降低张掌和握拳规则的可靠性。
- 掌面朝向是基于 landmarks 的近似估计，不是完整六自由度手部姿态。
- V1 没有人体识别、人物分割或深度模型；只识别手并把特效叠加在视频前方。

## 2. 坐标与摄像头

- 浏览器摄像头约束不保证获得请求的分辨率或帧率，实际值由设备和浏览器决定。
- 默认镜像画面与模型原始坐标不同；新增图层时必须复用统一 CoordinateMapper，否则容易出现双重镜像或裁剪偏移。
- 不同摄像头的视场角、自动曝光和自动对焦会影响掌宽到法阵尺寸的视觉映射。
- 未授权前摄像头名称可能为空；设备选择器需要在授权成功后刷新。
- 摄像头权限被永久拒绝后，应用无法主动重新弹出权限框，用户需要在浏览器站点设置中恢复。
- getUserMedia 需要 HTTPS 或 localhost；通过普通 HTTP 局域网 IP 打开时摄像头通常不可用。

## 3. V1 / V1.1 手势限制

- 当前包含张掌、握拳、双手法阵、捏合轨迹与严格双手快速展开。
- 捏合能量点位于拇指与食指中点，轨迹支持自由绘制和简单符号；没有圆形闭合识别、字符分类或“双手画圆激活”。
- 快速展开必须先形成有效靠近/压缩证据，再在 360 ms 窗口内达到扩张量和速度门槛；慢展开与初始已经分开的姿态会被有意拒绝。
- 阈值为通用启发式，不同手型、拍摄距离和镜头角度可能需要调整灵敏度。
- 持续握拳受冷却保护，不会重复爆裂；这也意味着在冷却结束前的第二次快速握拳可能被有意忽略。
- 双手法阵需要同时稳定识别两只手；任一手长时间被遮挡都会结束效果。

## 4. 特效限制

- V1 / V1.1 使用动态 Shader、几何圆环、固定池粒子、轨迹和冲击波，但不包含电影级后处理。
- Bloom、色差、折射、空间扭曲和动态模糊未完成，属于 V2。
- 人物遮挡、手掌透视和真实深度关系未完成，属于 V2。
- 粒子、轨迹段和冲击波已使用固定容量并受 Low / Balanced / High 三档限制；这能阻止实例无限增长，但不代表所有集成 GPU 都能稳定运行 High 档。
- WebGL context lost 的自动完整恢复尚未作为 V1 验收项；发生时可能需要刷新页面。

## 5. 音频

- V1 / V1.1 已提供默认关闭的原创 Web Audio 出现、爆裂、持续能量、捏合轨迹和冲击波合成音，并支持全局音量、节点复用与重复播放保护。
- Web Audio 受浏览器自动播放策略限制，必须由用户点击等交互解锁；控制面板会播放确认音并显示 ready / suspended / blocked 状态，应用不会主动绕过限制。

## 6. 性能

- 目标为普通电脑 30 FPS 以上，但尚不能脱离具体硬件、浏览器、分辨率和粒子配置作统一保证。
- 开启关键点、骨架和高频调试文本会增加 CPU 与 Canvas 开销。
- 高 DPR 显示器若不限制 renderer pixel ratio，GPU 开销会显著增大。
- 当前没有可代表所有设备的端到端 100 ms 延迟保证，最终应按 PERFORMANCE.md 的录屏方法记录参考结果。
- Worker 往返耗时、推理 FPS 和丢帧指标已可见，但尚无真实摄像头 60 秒基准或至少 15 分钟持续运行结果。

## 7. 浏览器与部署

- 当前自动烟测只覆盖 2026-08-01 的 Windows 无头 Edge 假摄像头生产预览环境；它确认 `WORKER`、V1.1 实绘且无页面异常、控制台/网络错误，但不替代 Chrome / Edge 真实摄像头或其他浏览器验证。
- production preview 必须确认本地 MediaPipe WASM 和模型路径；开发服务器可用不代表部署路径一定正确。
- 全屏必须由用户操作触发，且 Esc、切换标签页或切换应用可能退出全屏。
- 背景标签页中的 requestAnimationFrame 会暂停或节流，恢复后首帧时间差必须限幅。

## 8. 未完成的平台能力

- Tauri、Electron、Android、HarmonyOS 和 iOS 封装均未完成。
- 截图、录像、透明背景录制和虚拟摄像头输出均未完成。
- 自定义手势、自定义法阵和预设管理均未完成。

## 9. 尚待完成的验证

- Chrome 与 Edge 的真实摄像头授权、设备切换、不同宽高比和手势阈值验证。
- 60 秒性能基准、至少 15 分钟持续运行，以及固定池、Worker 和持续音频的长期资源检查。
- Firefox、Safari 与移动浏览器的兼容性验证。

## 10. 版权与素材

- V1 / V1.1 法阵、轨迹、冲击波和 Web Audio 使用原创程序化内容，不复制任何电影中的具体图案或声音。
- 不使用角色 Logo、电影截图、电影原声或未授权素材包。
- 后续新增模型、纹理和音效时，必须同时记录来源、许可证和本地文件对应关系。
