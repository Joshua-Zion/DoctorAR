# DoctorAR 手势规则

## 1. V1 / V1.1 范围

当前实现并纳入代码验证：

- 单手张掌。
- 单手握拳。
- 双手有效且距离合理时的双手法阵。
- 拇指与食指捏合时的中点能量点和自由空中轨迹。
- 严格“先靠近、后快速展开”的双手释放冲击波。

空中轨迹支持绘制简单符号并自动衰减，但当前没有圆形闭合识别、字符分类或“双手画圆激活”规则。

## 2. MediaPipe 手部关键点

Hand Landmarker 为每只手返回 21 个点：

| 编号 | 位置 |
| --- | --- |
| 0 | Wrist |
| 1–4 | Thumb CMC、MCP、IP、Tip |
| 5–8 | Index MCP、PIP、DIP、Tip |
| 9–12 | Middle MCP、PIP、DIP、Tip |
| 13–16 | Ring MCP、PIP、DIP、Tip |
| 17–20 | Pinky MCP、PIP、DIP、Tip |

归一化 x、y 以输入图像左上角为原点；world landmarks 用于补充三维几何，但不应被解释成消费级摄像头的精确深度。

## 3. 左右手与镜像

摄像头输入帧保持原始方向，用户看到的视频默认水平镜像。坐标映射负责将模型坐标映射到镜像显示区域。

界面中的 Left / Right 指人体解剖学左右手，不指屏幕左右。遮挡、手背、交叉或极端角度可能导致 handedness 短暂不稳定；连续帧应结合上一帧身份和位置，不能依赖结果数组下标。

## 4. 派生特征

### 手掌中心

使用 wrist 与四个 MCP 点，或四个 MCP 点的稳定加权平均。实现必须在代码和调试信息中采用同一公式。

### 手掌宽度

使用 index MCP 到 pinky MCP 的距离。内部建议保留归一化值，映射到屏幕后再计算显示尺寸。

### 屏幕旋转角

使用 index MCP 到 pinky MCP 的方向或掌部基准轴计算 atan2。角度应进行环绕感知的平滑，避免从正 180 度跳到负 180 度。

### 手指伸展

非拇指优先使用 MCP、PIP、DIP、Tip 的关节夹角和 tip 到 palm 的相对距离，不仅比较 y 坐标。拇指单独使用 CMC、MCP、IP、Tip 的几何规则。

### 掌面朝向

V1 使用 palm world landmarks 的叉乘法向或二维掌部几何进行近似判断。它是轻量启发式，不是完整手掌姿态估计；侧掌和手背场景的限制记录在 KNOWN_ISSUES.md。

单手张掌继续使用朝向摄像头的门控；双手法阵不复用这一分数，而是独立检查四根长指伸展度。双掌相对可进入；双掌同时朝前时还必须处于较近距离且掌心高低差不超过门槛。

### 速度和双手距离

- 手部速度：平滑掌心位置对真实时间的导数。
- 双手距离：两只平滑掌心的距离。
- 双手相对速度：当前距离减上一有效距离，再除以真实秒数。

速度不能按“每帧位移”表示，否则不同刷新率会产生不同阈值。

## 5. 置信度定义

MediaPipe Web HandLandmarkerResult 提供 handedness 分类分数、21 点坐标和 world landmarks，但不提供逐关键点置信度。以下概念必须区分：

- minHandDetectionConfidence、minHandPresenceConfidence、minTrackingConfidence 是模型配置门槛。
- handedness score 是左右手分类分数。
- gesture confidence 是 DoctorAR 根据手指、朝向、距离和时间稳定性派生的规则分数。

调试界面不得把配置门槛或常量伪装成逐关键点实时置信度。

## 6. 平滑与丢失策略

V1 默认对位置、宽度、旋转和距离做指数平滑。平滑强度可配置，并预留替换 One Euro 或 Kalman 的接口。

识别暂时丢失时：

1. 在最大中断时间内保留最后有效姿态。
2. 超过保持时间后逐渐降低效果透明度。
3. 超过最终超时才结束 Active 状态并隐藏效果。
4. 重新识别后从当前透明度平滑恢复，不能跳到错误位置。

## 7. 通用状态机

每个手势使用：

- Idle：没有候选。
- Candidate：条件满足但尚未达到最短保持时间。
- Active：手势稳定生效。
- Released：退出条件持续满足，发送一次结束事件。
- Cooldown：禁止立即重复触发。

进入阈值与退出阈值必须不同，以形成滞回。每个手势的最短保持、最大中断、冷却和置信门槛来自 gestureConfig，不在组件中散落常量。

## 8. 单手张掌

候选条件：

- 至少四根手指明显伸展，拇指使用独立规则。
- 手掌宽度达到最低可用值。
- 掌面大致朝向摄像头。
- 手部整体置信度高于门槛。

激活行为：

- 在平滑手掌中心显示单手法阵。
- 法阵尺寸随平滑掌宽单调变化，并有最小和最大限幅。
- 法阵基础角度随掌部屏幕旋转变化，同时保留视觉层自身缓慢自转。

退出行为：

- 条件短暂失败时使用最大中断时间。
- 长时间失败或手离开画面后渐隐。

## 9. 单手握拳

候选条件：

- 大多数手指弯曲。
- 掌部尺寸和手部置信度有效。
- 状态稳定达到最短保持时间。

触发行为：

- 对当前手的法阵发送一次 `FIST`。
- 法阵快速收缩并产生一次默认约 180 粒的能量爆裂；单次数量按性能档限制，避免过绘。
- 进入冷却；持续握拳不得每帧重复爆裂。

若当前手没有活动法阵，实现可以只更新握拳调试状态而不生成无来源的连续爆裂。重新张掌并完成冷却后才允许下一次完整触发。

## 10. 双手法阵

候选条件：

- 同时存在两只稳定手。
- 两手身份有效，双掌距离处于最小和最大范围之间。
- 四根长指伸展分数至少为 0.62。
- 双掌相对分数至少为 0.42；或双掌朝前分数至少为 0.66、距离不超过 0.54 个画面宽度且掌心纵向差不超过 0.20。
- 条件连续保持约 130 ms；候选中断达到 80 ms 后必须重新计时。

激活行为：

- 法阵中心为两只平滑掌心的中点。
- 法阵尺寸随双手距离单调变化，并有安全限幅。
- 连续更新 center、distance、relativeVelocity 和 opacity。
- Active 后改用较宽松的距离与伸展保持条件，不再持续套用严格进入门槛，以免快速展开阶段被提前终止。

退出行为：

- 任一手短暂丢失时保持并渐隐。
- 距离超过退出阈值或中断超时后发送一次 `TWO_HAND_CHARGE_END`。

冲突规则：双手法阵的优先级高于两个单手张掌法阵。进入双手 Active 后，单手法阵应抑制或平滑淡出；退出双手状态后再按各自手势恢复，避免同一位置叠加三个法阵。

## 11. 捏合与空中轨迹

候选与状态：

- 捏合分数来自拇指尖与食指尖距离相对掌宽的归一化结果。
- 使用独立进入/退出阈值、60 ms 最短保持、160 ms 独立冷却和短暂中断容忍，避免临界距离抖动；全局握拳冷却不会覆盖捏合冷却。
- 激活时发送一次 `PINCH_START`，保持时发送 `PINCH_MOVE`，退出时发送一次 `PINCH_END`。

位置与效果：

- 三类事件的位置统一为拇指尖 landmark 4 与食指尖 landmark 8 的中点，而不是任一指尖或掌心。
- `PINCH_START / MOVE` 驱动中点能量点；移动距离达到轨迹采样间距后追加发光轨迹段。
- 若异步特效加载期间漏掉 `PINCH_START`，首个未阻塞的 `PINCH_MOVE` 会自行建立轨迹，不会永久丢失本轮绘制。
- 松开、丢失或停止移动后，能量点和轨迹按各自寿命衰减，不永久保留。
- 左右手有独立状态，可分别绘制自由轨迹和简单符号。

轨迹没有闭合检测。绘出近似圆形只会得到圆形视觉轨迹，不会触发“识别成功”事件。

## 12. 严格双手快速展开

`TWO_HAND_RELEASE` 从双手候选阶段开始保留靠近历史，但只有双手法阵进入 Active 后才允许发出，并强制以下顺序：

1. 两手先明显靠近，或持续进入近距离区间，形成压缩证据。
2. 压缩或近距离证据保持至少 70 ms 后才进入 armed 状态。
3. 从 armed 最小距离开始向外扩张；扩张开始后必须在 360 ms 窗口内达到至少 0.055 个画面宽度的扩张量与 0.5 个画面宽度/秒的滤波速度。
4. 成功只发送一次事件并进入冷却。慢展开、刚进入画面时已经分开、跟踪失效或超时都不会触发；无效跟踪会复位已武装序列。

默认检测器使用 420 ms 固定容量历史窗口寻找靠近证据，允许一次短暂漏帧；候选姿态失效时不会继续积累释放证据，80 ms 旧数据及其第一帧重识别跳变也不会触发。候选阶段已经达到的释放条件仅短暂锁存，重新合掌后不会补发冲击波。

触发后的视觉由特效层负责：冲击波以双手中点为中心，终止半径按该点到视口最远角计算，不由手势层硬编码像素尺寸。
